# 0003. Apache license

- Status: Accepted
- Date: M0

## Context

The license was an open question (Q1: permissive or copyleft). The project is
open-source and expects both first-party and community domain packs.

## Decision

The project is licensed under the Apache License, Version 2.0.

## Consequences

- A permissive license with an explicit patent grant encourages commercial and
  community adoption, including of packs.
- Redistributions must carry the license and the `NOTICE` file.
- The `NOTICE` file records the copyright notice and the standards-copyright
  warning (ISO, IEC, AISC, Eurocodes: cite clause numbers, do not reproduce
  standard text; cited data must carry a source column).
